# ESP32-WiFi-Walkie-Talkie
ESP32-based real-time Wi-Fi Walkie-Talkie using UDP audio streaming, INMP441 I2S microphone and MAX98357A I2S audio amplifier.
ESP32 Wi-Fi Walkie-Talkie
==========================

An ESP32-based real-time Wi-Fi Walkie-Talkie designed for voice
communication using UDP audio streaming.

Main Features
-------------
- ESP32-based wireless communication
- Real-time UDP audio streaming
- I2S digital microphone
- I2S audio amplifier
- Push-to-Talk (PTT) control
- Custom PCB designed in KiCad
- Schematic and PCB layout
- 3D PCB visualization

Hardware
--------
- ESP32
- INMP441 I2S microphone
- MAX98357A I2S audio amplifier
- Push-to-Talk button
- Custom-designed PCB

Tools
-----
- KiCad
- Arduino IDE

Repository Contents
-------------------
- KiCad schematic
- KiCad PCB layout
- Arduino PTT code
- PCB design images
